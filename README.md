One command-line tool that applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON — to a tree of files, to the written specification (SPEC.md).

## Run it

```sh
node main.ts [options] [PATCH]
```
